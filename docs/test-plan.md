## Quality Gates definidos

1. ✅ Todas las pruebas automatizadas deben pasar.
2. ⚙️ El porcentaje de errores en pruebas de performance debe ser menor al 1%.
3. ⏱️ El tiempo de respuesta promedio debe estar dentro del umbral definido (por ejemplo, < 2s).
4. 🔒 No deben existir secretos expuestos en el repositorio.
5. 📎 El Pull Request debe incluir evidencia o artefactos generados (reportes HTML, logs, capturas).
